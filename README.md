# FootballDataHub V2

Herramienta interna para adquirir y auditar datos de fútbol. El alcance inicial es Primera Federación 2026/27, Grupos I y II, con BDFutbol como primera fuente.

El Hito 0 documentó la estructura del sitio. El [Hito 1B](docs/hito_1b_competition_scraper.md) implementa el primer extractor reutilizable para clasificaciones, participantes y calendario/resultados de competición. Las salidas parsed se generan desde snapshots raw verificables; los scrapers de plantillas y entidades individuales quedan para hitos posteriores.
